2.What is Cascading in CSS? Give a real-time example?
	Cascading means deciding which CSS rule should be applied when more than one rule targets the same element. The browser chooses the rule based on priority.
	
	real-time example:
	<p class="Para">Hello</p>
	p{
	color: blue;
	}

	.text{
	color: red;
	}
	The paragraph will be red because the class selector has a higher priority than the element selector

9.What is the Difference Between Padding and Margin?
		Padding:
		*Space inside the border
		*Creates space between the content and the border
		*Background color extends into the padding area
		*Increases the element's internal spacing
		Margin:
		*Space outside the border.
		*Creates space between the element and other elements
		*Background color does not extend into the margin area
		*Creates external spacing between elements
		
10.What is box-sizing:border-box? Why is it recommended?
		The box-sizing: 
		border-box property changes how the width and height of an element are calculated
		By default the width and height of an element include only the content If you add padding and border the actual size of the element becomes larger
		When you use box-sizing: border-box the padding and border are included within the specified width and height This means the total size of the element remains the same
		Why is it Recommended:
		*Keeps the width and height predictable because padding and border are included in the specified size.
		*Prevents layout and overflow issues when adding padding or borders
		*Makes responsive design easier by avoiding manual size calculations
		Widely used in realworld projects because it simplifies CSS and makes layouts easier to maintain 
		
		*{
		box-sizing: border-box;
		}

15.How do you perfectly center a div using Flexbox?Write the CSS code and explain each property
		Flexbox provides a simple way to center a <div> both horizontally and vertically First make the parent element a flex container 
		Then use justify-content and align-items to place the child element in the center
		
		<div class="box">
		<div class="box">box1</div>
		</div>
		css code:
		.box{
		display: flex;
		justify-content: center;
		align-items: center;
		text align:center;
		height: 100px;
		}
		
	display: flex:
	This property turns the parent element into a flex container All the direct child elements become flex items
	justify-content: center:
	This property centers the child element along the main axis By default the main axis is horizontal so it centers the <div> from left to right
	align-items: center;
	This property centers the child element along the cross axis By default the cross axis is vertical so it centers the <div> from top to bottom
	height:600px;
	This sets the container height to 600px allowing the child <div> to be centered vertically
